# 기존 시나리오는 검토 후 게시하고 과거 세션의 설정을 역사적 사실로 복원하지 않는다

기존 학생 프로필은 공개 화면에 쓰였지만 내부 연기 지시와 분리되어 있지 않고, 세션 시작 시점의 설정 사본도 없다. 이전 시 학생 프로필 원문은 내부에 보존하고 공개 소개는 관리자가 선정한다. 변환한 시나리오는 초안과 검토 필요 상태로 두며, 기존 세션의 재구성 설정은 출처와 복원 시각·확인 불가 항목을 표시하고 읽기 전용으로 보존한다.

자동 게시와 과거 세션의 재실행을 허용하면 편의는 높지만, 공개 범위를 추측하거나 현재 설정으로 만든 결과를 과거 수업의 결과처럼 취급하게 된다. 전환 전 진행 중 세션을 완료하고, 새 연습만 검토된 설정으로 시작한다. 변환은 기존 ID·메시지·정상 분석을 바꾸지 않으며 누락된 기준이나 모델을 추측해서 채우지 않는다.
