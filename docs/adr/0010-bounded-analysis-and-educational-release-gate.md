# 장문 사후 분석은 범위를 공개한 제한적 분할과 교육 품질 승인으로 전환한다

일반 대화는 하나의 구조화 호출로 분석하고, 입력 또는 예상 출력이 넘으면 완료 턴을 보존한 최대 8개 분할과 한 번의 종합으로 제한한다. 직전 한 턴은 참고 맥락으로만 중복하고 분류 담당 메시지는 겹치지 않는다. 한 턴이나 최종 종합이 예산에 들어가지 않으면 실행 전에 차단하며, 전체 대화를 몰래 줄이거나 모델·옵션을 자동 변경하지 않는다.

분할은 문맥 손실과 호출 비용을 늘릴 수 있으므로 교사에게 범위·호출 수·추정임을 먼저 표시하고 실행 의사를 받는다. 실패한 분할을 정상 전체 분석으로 종합하지 않고 검증된 범위만 부분 분석으로 표시한다. 구조 검증과 역할 시험은 교육적 품질을 보장하지 않으므로, 고정 합성 대화 표본의 S2 대비 검토와 교육 담당자의 승인 기록이 없으면 S4를 출시하지 않는다. 승인은 해당 모델·옵션·프롬프트·스키마·분할 정책에 한정된다.

결정 근거: PRD §7.4·§8·AC-22/23/28, S4 #20 설계 Q8–Q14. 사용자의 “모두 자동 승인, 권장 사항으로 진행”으로 설계·게시를 승인받았으며, 향후 실제 교육 품질 평가나 유료 호출을 승인한 것은 아니다.
