# 동일 맥락 비교는 수업 기록과 분리하고 공통 입력을 그대로 실행한다

관리자 비교는 별도 비교 실행에 입력·설정·패널을 고정하고, 기존 생성 실행 기록에 비교 소속을 추가한다. 생성 실행은 수업 세션 또는 비교 실행 중 정확히 하나에 속한다. 비교를 임시 수업 세션으로 만들면 수업 통계·연구 CSV와 분석 결과 저장 경로에 실험 데이터가 섞이므로, 제공자 호출·출력 검증은 재사용하되 수업 메시지·분석 결과 저장은 재사용하지 않는다.

모든 패널은 같은 기준 대화 이력과 역할 지시를 받는다. 모델 하나라도 입력·출력 예산을 넘으면 호출 전에 전체 비교를 막고 관리자가 공통 입력을 수정한다. 학생·멘토의 모델별 자동 절삭과 사후 분석의 모델별 장문 분할을 비교에 적용하지 않는다. 분석 비교는 패널당 한 번의 구조화 호출만 허용한다. 수업 실행을 그대로 재사용하는 편의보다 서로 다른 모델이 실제로 같은 내용을 평가했다는 의미를 우선한다. ADR-0009의 수업 문맥 절삭과 ADR-0010의 수업 사후 분석 분할 정책은 그대로 유지한다.

비교 입력·출력은 생성 시점부터 30일 뒤 만료하며, 명시적 삭제와 정리 명령은 비교에 속한 생성 실행까지 삭제한다. 비용 원장은 본문 없이 보존하고 삭제 전에 생성 실행 참조를 해제하되 비교 비용이라는 구분은 남긴다. 비교 자료 보존기간이 지났다는 이유로 이미 발생한 비용을 지우거나 수업 비용으로 재분류하지 않는다.

결정 근거: S5 #21 grilling. Q1은 사용자가 단일 호출 분석 비교 권장안을 직접 승인했다. 이후 사용자가 남은 모든 grilling 질문의 권장안을 승인하고 추가 질문 없이 spec 게시를 지시했다. 구현 티켓 게시 승인은 별도로 받는다.
