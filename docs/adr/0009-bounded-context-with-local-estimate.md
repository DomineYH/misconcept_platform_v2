# 대화 문맥은 로컬 추정으로 오래된 완전한 턴만 줄이고 필수 입력은 보존한다

학생·멘토는 수업 설정 스냅샷의 문맥 턴 수와 모델 옵션을 유지하되, 제공자별 입력·문맥 한도와 출력 여유분을 확인한 후 호출한다. 별도 토큰 계산 API나 요약 생성 호출 대신 보수적인 로컬 추정을 사용하고 추정 방식·포함한 턴 수를 사용량 기록의 별도 메타데이터에 남긴다. 추정치는 실제 사용 토큰이나 과금 값으로 사용하지 않는다.

기존 의미인 최근 N개 선행 완료 턴과 현재 교사 발화(멘토는 완료된 대상 턴)를 유지하며, 초과 시 가장 오래된 선행 턴부터 쌍 전체를 제외한다. 역할 지시·문제·현재 입력은 자르지 않고 출력 옵션도 몰래 낮추지 않는다. 필수 입력만으로도 초과하면 외부 호출 전에 거부한다. 요약 호출을 피하는 대신 오래된 세부 맥락이 빠질 수 있고, 추정이므로 제공자의 한도 오류까지 없애지는 못한다.

이 정책은 대화 중 학생·멘토에만 적용한다. 사후 분석의 전체 대화 보존·분할은 S4, 비교의 공통 문맥 결정은 S5 소유이며 각 패널의 독립 절삭으로 확장하지 않는다. ADR-0002의 스냅샷 문맥 턴 수와 live 운영 시간 제한 경계를 유지한다.

결정 근거: S3 #19 설계에서 제품 소유자가 권장안을 사전 승인했다. 정확한 추정식과 오류 계약은 [S3 명세 #71](https://github.com/DomineYH/misconcept_platform_v2/issues/71)에 기록했다.
