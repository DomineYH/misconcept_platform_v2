# 멘토의 판단과 코칭을 하나의 결과로 검증하고 판단 근거는 비공개로 보존한다

자동 멘토의 판단 뒤 별도 코칭 호출은 지연·비용을 늘리고 두 결과의 일관성을 따로 관리하게 한다. 수동·자동 도움 모두 단일 구조화 결과인 should_intervene, feedback, reason_summary를 검증하며, 수동 도움은 코칭을 요구하고 자동 검사만 미개입을 허용한다. 기존 턴·실행·정책 경계를 유지하고 유효한 결과를 저장한 뒤에만 교사에게 완료를 알린다.

미개입에도 판단 근거는 실행 기록에 보존하지만 내부 학생 설정·개입 조건을 담을 수 있으므로 교사 화면·상태 API·CSV에는 전달하지 않는다. 코칭 본문은 기존 메시지에, 개입 여부는 기존 결과 종류에 저장하여 전체 구조화 결과를 중복 저장하지 않는다. 원문 추론이 아닌 짧은 판단 설명을 요구하며, 잘못된 결과를 수선하는 추가 호출은 하지 않는다.

이 변경은 멘토 역할 계약을 s3-v1로 바꾸므로 기존 멘토 검증은 재검증이 필요하다. 학생·분석 출력 계약은 유지한다. 과거 코칭·사용량을 새 형태로 추측 변환하지 않는다.

결정 근거: S3 #19 설계에서 제품 소유자가 “모두 자동 승인, 권장 사항으로 진행”으로 권장안과 게시를 사전 승인했다. 상세 결정은 [S3 명세 #71](https://github.com/DomineYH/misconcept_platform_v2/issues/71)에 기록했다.
