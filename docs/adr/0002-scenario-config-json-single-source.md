# 시나리오 실행 설정은 `config_json` 단일 원본, 세션은 시작 시 스냅샷

학생봇·멘토·사후 분석 설정과 역할별 모델을 별도 템플릿·분석 틀 테이블에서 참조하던 구조를 버리고, 시나리오 안의 버전 붙은 `config_json` 하나를 실행 원본으로 삼는다. 검색·권한 필드(제목, 그룹, 상태)만 정규 컬럼에 남긴다. 새 세션은 시작 시점의 완성된 설정을 스냅샷으로 저장해, 이후 시나리오·모델 기본값 변경이 진행 중·종료 세션에 영향을 주지 않는다. 개별 컬럼과 JSON을 동시에 읽는 이중 원본 기간은 두지 않는다.

## Considered Options

- 템플릿·분석 틀 테이블 유지 + 시나리오별 오버라이드: 관리자가 "먼저 저장하고 선택하는" 절차가 남아 PRD 목표와 충돌.
- 설정 필드를 전부 정규 컬럼화: 자유 서술 위주의 설정에 비해 스키마 변경 비용이 큼.
