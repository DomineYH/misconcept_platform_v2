# 오개념 판별은 턴마다 하지 않고 사후 분석에서만 한다

기존에는 학생 응답마다 `MisconceptionAnalyzer`를 별도 LLM 호출로 실행해 `message.metadata`에 저장했지만, 그 값을 읽는 화면·CSV·분석이 하나도 없었다. 학생 턴의 필수 호출을 1회로 줄이기 위해 턴별 판별을 제거하고, 오개념 유지·변화 근거는 사후 분석의 단일 구조화 출력에서 메시지 ID와 함께 산출한다. 이미 저장된 `metadata` 값은 보존하되 새로 쓰지 않는다. 실시간 오개념 수치가 필요한 연구가 생기면 별도 노력으로 다룬다.
