# 제공자 API 키는 DB에 암호화 저장하고 마스터 키만 환경 설정에 둔다

관리자가 코드나 `.env` 수정 없이 OpenAI·Anthropic·Google 키를 교체할 수 있어야 하므로, 제공자 키는 AES-256-GCM(검증된 `cryptography` 라이브러리)으로 암호화해 DB에 저장하고 호출 직전에 복호화한다. 마스터 키(`PROVIDER_SECRET_ENCRYPTION_KEY`)는 `SESSION_SECRET`과 분리된 인프라 비밀로 환경 설정에서만 공급한다. `.env`의 기존 `OPENAI_API_KEY`를 읽는 영구 폴백과 1회성 가져오기 도구는 두지 않는다 — 파일럿 규모라 관리자가 새 화면에서 다시 입력한다.

## Consequences

- 마스터 키를 잃으면 저장된 모든 제공자 키를 복구할 수 없다. DB 백업과 함께 마스터 키 버전을 별도로 보관한다.
- 키 저장·교체·삭제는 요청마다 관리자 비밀번호를 다시 확인한다(최근 로그인 시각 방식이 아님).
