# 분류 라벨

스킬에서 사용하는 다섯 가지 표준 분류 역할을 이 저장소의 실제 라벨 문자열에 대응시킨다.

| 스킬의 역할 | 트래커의 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 이슈 검토가 필요함 |
| `needs-info` | `needs-info` | 요청자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세가 확정되어 에이전트가 독립적으로 착수할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 함 |
| `wontfix` | `wontfix` | 작업하지 않기로 결정함 |

스킬이 분류 역할을 언급하면 이 표의 대응 라벨 문자열을 그대로 사용한다. 사용하는 라벨 체계를 바꾸려면 트래커의 라벨 열을 수정한다.
