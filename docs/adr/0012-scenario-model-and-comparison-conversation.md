# 공통 시나리오 모델과 비교 대화는 기존 역할 실행을 재사용한다

관리자가 저장된 시나리오를 선택하고 최대 세 모델의 전체 동작을 여러 턴에 걸쳐 비교하는 흐름을 승인했다. 시나리오 모델의 공통 선택은 기존 역할별 설정에 같은 모델 정체성을 저장하는 작성 규칙으로 구현하고, 역할별 옵션과 기존 수업 스냅샷은 보존한다. 이는 ADR-0002의 독립적인 역할별 모델 선택을 새 작성·편집에서 대체하지만, 설정의 단일 원본과 실행 시점 고정 원칙은 유지한다.

비교 대화는 고정된 시나리오·모델 설정과 채택한 공통 대화 기록을 소유하고, ADR-0011의 역할별 비교 실행을 하위 작업으로 묶는다. 학생 응답 하나를 명시적으로 채택해 모든 모델의 다음 입력을 동일하게 유지하며, 멘토 결과와 최종 분석은 공통 학생 대화에 넣지 않는다. 새 제공자 실행 경로를 만들거나 비교를 수업 세션으로 저장하면 기존 검증·비용·연구 자료의 경계를 다시 구현해야 하므로 채택하지 않았다.

비교 대화와 모든 하위 결과는 최초 생성부터 30일 뒤 함께 만료하고 비용 원장은 보존한다. 기존 역할별 비교 이력과 서로 다른 역할 모델을 가진 시나리오는 일괄 변환하지 않으며, 시나리오를 편집·저장할 때 공통 모델을 명시적으로 선택한다. 이 결정은 2026-10-13 설계 인터뷰 Q1–Q19와 최종 합의에 대한 사용자의 구현 확인을 근거로 한다.
