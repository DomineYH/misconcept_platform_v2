# 검증된 복사본으로 전환하고 새 쓰기 이후에는 자동 복원하지 않는다

파일럿 전환은 모든 쓰기를 중지한 원본의 일관된 복사본에서 기존 변환·보존 검증·정리 절차와 후속 마이그레이션을 완료한 뒤, 검증된 후보와 코드 버전을 함께 설치한다. 이미 보존 영수증을 요구하는 031을 단순 일괄 SQL로 우회하지 않으며, S6의 기술적 완료와 실제 운영 전환을 분리해 HG1–HG5 및 운영 검증·별도 전환 승인이 갖춰질 때까지 운영 DB를 전환하지 않는다.

새 버전이 기록을 쓰기 전의 실패는 이전 DB·코드·설정·키 버전으로 복원할 수 있다. 기동 복구, 관리자 설정, 사용량을 포함한 새 쓰기가 하나라도 생기면 양쪽 DB를 보존·대조하고 전진 수정을 우선하며, 신규 기록 손실을 승인 없이 숨기는 자동 복원이나 무손실 다운그레이드를 제공하지 않는다. 단순한 복원 버튼의 편의보다 수업·연구·과금 기록의 보존을 우선한 결정이다.

결정 근거: S6 #22 grilling. Q1은 사용자가 직접 승인했고, Q2와 나머지 권장안은 사용자의 일괄 승인으로 확정했다. 명세 게시 승인은 구현 티켓 게시, 실제 교육 품질 판정, 유료 호출 또는 운영 전환 승인과 구분한다.
