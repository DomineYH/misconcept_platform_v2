# 채택한 사후 분석과 최신 실행 결과를 분리한다

재분석이 부분 성공하거나 실패해도 교사가 이미 받은 정상 분석은 유지해야 한다. 기존 분류·구조화 피드백·요약 테이블을 채택 결과로 유지하고, 요청 식별·분할 계획·실행 상태·누락 범위는 별도 사후 분석 실행 기록에 남긴다. 새 결과의 근거 검증이 끝난 후 세 결과를 한 트랜잭션으로 교체하며, 부분 분석은 정상 또는 과거 정상 결과를 덮어쓰지 않는다.

하나의 보고서 상태에 최신 실패를 덮어쓰는 방식은 기존 내용이 실패 결과처럼 보이고, 저장 직전 중복 검사만으로는 재전송의 중복 유료 호출을 막지 못한다. 실행 기록은 이를 위한 최소 경계이며 범용 작업 큐나 모든 보고서 버전 보관소로 확장하지 않는다. 과거 결과는 재작성하지 않고 버전에 맞춰 읽는다.

결정 근거: S4 #20 설계, Q6/Q7. 사용자의 “모두 자동 승인, 권장 사항으로 진행” 및 게시 사전 승인으로 확정.
